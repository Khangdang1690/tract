<h2>
Project description
</h2>
<div>
<h1>
Requests
</h1>
<p>
<a>
<img>
</a>
<a>
<img>
</a>
<a>
<img>
</a>
<a>
<img>
</a>
<a>
<img>
</a>
</p>
<p>
<strong>
Requests
</strong>
is a simple, yet elegant, HTTP library.
</p>
<pre>
<span>
>>>
</span>
<span>
import
</span>
<span>
</span>
<span>
requests
</span>
<span>
>>>
</span>
<span>
r
</span>
<span>
=
</span>
<span>
requests
</span>
<span>
.
</span>
<span>
get
</span>
<span>
(
</span>
<span>
'https://httpbin.org/basic-auth/user/pass'
</span>
<span>
,
</span>
<span>
auth
</span>
<span>
=
</span>
<span>
(
</span>
<span>
'user'
</span>
<span>
,
</span>
<span>
'pass'
</span>
<span>
))
</span>
<span>
>>>
</span>
<span>
r
</span>
<span>
.
</span>
<span>
status_code
</span>
<span>
200
</span>
<span>
>>>
</span>
<span>
r
</span>
<span>
.
</span>
<span>
headers
</span>
<span>
[
</span>
<span>
'content-type'
</span>
<span>
]
</span>
<span>
'application/json; charset=utf8'
</span>
<span>
>>>
</span>
<span>
r
</span>
<span>
.
</span>
<span>
encoding
</span>
<span>
'utf-8'
</span>
<span>
>>>
</span>
<span>
r
</span>
<span>
.
</span>
<span>
text
</span>
<span>
'{"authenticated": true, ...'
</span>
<span>
>>>
</span>
<span>
r
</span>
<span>
.
</span>
<span>
json
</span>
<span>
()
</span>
<span>
{
</span>
<span>
'authenticated'
</span>
<span>
:
</span>
<span>
True
</span>
<span>
,
</span>
<span>
...
</span>
<span>
}
</span>
</pre>
<p>
Requests allows you to send HTTP/1.1 requests extremely easily. There’s no need to manually add query strings to your URLs, or to form-encode your
<code>
PUT
</code>
&
<code>
POST
</code>
data — but nowadays, just use the
<code>
json
</code>
method!
</p>
<p>
Requests is one of the most downloaded Python packages today, pulling in around
<code>
300M downloads / week
</code>
— according to GitHub, Requests is currently
<a>
depended upon
</a>
by
<code>
4,000,000+
</code>
repositories.
</p>
<h2>
Installing Requests and Supported Versions
</h2>
<p>
Requests is available on PyPI:
</p>
<pre>
<span>
$
</span>
python
<span>
</span>
-m
<span>
</span>
pip
<span>
</span>
install
<span>
</span>
requests
</pre>
<p>
Requests officially supports Python 3.10+.
</p>
<h2>
Supported Features & Best–Practices
</h2>
<p>
Requests is ready for the demands of building robust and reliable HTTP–speaking applications, for the needs of today.
</p>
<ul>
<li>
Keep-Alive & Connection Pooling
</li>
<li>
International Domains and URLs
</li>
<li>
Sessions with Cookie Persistence
</li>
<li>
Browser-style TLS/SSL Verification
</li>
<li>
Basic & Digest Authentication
</li>
<li>
Familiar
<code>
dict
</code>
–like Cookies
</li>
<li>
Automatic Content Decompression and Decoding
</li>
<li>
Multi-part File Uploads
</li>
<li>
SOCKS Proxy Support
</li>
<li>
Connection Timeouts
</li>
<li>
Streaming Downloads
</li>
<li>
Automatic honoring of
<code>
.netrc
</code>
</li>
<li>
Chunked HTTP Requests
</li>
</ul>
<h2>
Cloning the repository
</h2>
<p>
When cloning the Requests repository, you may need to add the
<code>
-c fetch.fsck.badTimezone=ignore
</code>
flag to avoid an error about a bad commit timestamp (see
<a>
this issue
</a>
for more background):
</p>
<pre>
git
<span>
</span>
clone
<span>
</span>
-c
<span>
</span>
fetch.fsck.badTimezone
<span>
=
</span>
ignore
<span>
</span>
https://github.com/psf/requests.git
</pre>
<p>
You can also apply this setting to your global Git config:
</p>
<pre>
git
<span>
</span>
config
<span>
</span>
--global
<span>
</span>
fetch.fsck.badTimezone
<span>
</span>
ignore
</pre>
